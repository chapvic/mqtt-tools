ЖУРНАЛ ИЗМЕНЕНИЙ
=================

mqtt_pub — Многопоточный MQTT-публикатор для встраиваемых Linux-систем
======================================================================

v1.0
--------------------

  Первый релиз:

  - INI-парсер конфигурации (секция [MQTT] + секции метрик).
  - Три типа источников:
    - Файл: чтение значения из файла через open()+read().
    - Shell-команда (@): выполнение shell-команды через popen(), чтение stdout.
    - Удалённый брокер ($): подписка на топик удалённого MQTT-брокера и
      републикация полученных значений на локальный брокер.
  - Параметр key= для извлечения значения:
    - Литеральный ключ: поиск key=<значение> в содержимом, публикация <значения>.
    - Regex-ключ (/pattern/): POSIX ERE с поддержкой группы захвата.
    - key=-: публикация полного содержимого (по умолчанию, если key не задан).
  - Формат удалённого источника: $[user:pass@]host:port/topic
    - Опциональная аутентификация (user:pass@).
    - Валидация хоста (алфавитно-цифровые символы, точки, дефисы).
    - Валидация порта (1-65535, по умолчанию 1883).
  - Гибридный режим для удалённых метрик:
    - Событийный (без interval): публикация при получении каждого сообщения.
    - Републикация по таймеру (с interval): периодическая републикация
      последнего известного значения, обновление при новых сообщениях.
  - Разделяемые подключения к удалённым брокерам: дедупликация по host:port
    (MAX_REMOTES=32).
  - Отдельный pthread на метрику с настраиваемым интервалом и QoS.
  - mosquitto_publish с глобальным мьютексом (g_mqtt_mutex) для потокобезопасности.
  - Параметрический value_mutex для удалённых метрик (разделяется между
    коллбэком remote_on_message и потоками-таймерами).
  - Авто-реконнект для локального и удалённых брокеров:
    - mosquitto_reconnect_delay_set(1, 60, false) — 1с начальная задержка,
      60с максимум, линейный backoff.
    - Удалённые брокеры используют mosquitto_connect_async (неблокирующее).
    - Переподписка на все топики при реконнекте (коллбэк remote_on_connect).
  - Отказоустойчивость: недоступные удалённые брокеры не блокируют локальные метрики.
  - Повтор подключения к локальному брокеру с однократным логированием ошибки.
  - Ожидание CONNACK с опросом каждые 100мс (до 2 секунд).
  - Коллбэки on_connect / on_disconnect (локальные и удалённые).
  - Обработка SIGINT/SIGTERM с плавной остановкой:
    - Флаг g_running проверяется с шагом 100мс.
    - Упорядоченное завершение: join потоков, loop_stop(force=true) для всех
      брокеров, disconnect, destroy, lib_cleanup.
  - Аутентификация username/password для локального и удалённых брокеров.
  - Валидация конфигурации: дубликаты секций, дубликаты топиков, отсутствие
    обязательных полей, недопустимые порты, диапазон QoS, лимиты буферов,
    максимум метрик.
  - Режим отладки (debug=1): подробный вывод опубликованных значений,
    событий подключения, ошибок источников, подписок на удалённые топики.
  - Лимиты буферов: MAX_VALUE(256), MAX_SHELL_CMD(2048), MAX_SECTION(64),
    MAX_TOPIC(512), MAX_LINE(4096), MAX_METRICS(128), MAX_HOST(256),
    MAX_USER(64), MAX_PASS(256), MAX_KEY(64), MAX_RAW(8192),
    MAX_REMOTE_TOPIC(512), MAX_REMOTES(32).
  - Makefile с целями:
    - make: сборка mqtt_pub.
    - make install: установка бинарного файла, systemd-юнита, конфига, env-файла.
      - Локальный mqtt_pub.ini в папке проекта копируется в назначение
        (с сохранением пользовательских метрик), с применением параметров
        HOST/PORT/MQTT_USER/MQTT_PASS через sed.
      - При отсутствии локального конфига — динамическая генерация или
        обновление существующего.
      - Env-файл в /etc/default/mqtt_pub с PARAMS=-f <путь_к_конфигу>.
      - install.log сохраняет путь CONF для будущих обновлений.
    - make uninstall: удаление всех установленных файлов (install.log сохраняется).
    - make clean: удаление скомпилированного бинарного файла.
    - make distclean: удаление бинарного файла и install.log.
  - Файл systemd-сервиса (mqtt_pub.service).
  - Пример конфигурации (mqtt_pub.ini.example).
  - Документация: README.md, README_RU.md, docs/MQTT_Publisher.md,
    docs/MQTT_Publisher_RU.md.
