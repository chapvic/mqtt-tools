# MQTT Publisher

Многопоточный MQTT-публикатор для Linux, читающий метрики из INI-конфигурационного
файла и публикующий их на локальный MQTT-брокер с заданными интервалами.

Поддерживает три типа источников: файлы, shell-команды и подписку на удалённые
MQTT-брокеры с автоматическим републикованием.

## Возможности

- **Многопоточность:** каждая метрика работает в отдельном потоке с собственным интервалом публикации.
- **Три типа источников:** чтение из файлов, выполнение shell-команд, подписка на удалённые MQTT-брокеры.
- **Извлечение значения по ключу:** поиск `key=value` в содержимом источника (`key=T` ищет строку `T=<значение>`) или через POSIX ERE regex (`key=/^pattern$/`).
- **Удалённые метрики:** подписка на топики удалённого брокера через `$[user:pass@]host:port/topic` и републикация на локальный брокер. Событийный режим (без interval) или републикация по таймеру (с interval).
- **Разделяемые подключения:** несколько метрик на одном `host:port` используют один экземпляр mosquitto.
- **Авто-реконнект:** локальный и удалённые брокеры автоматически переподключаются с ограниченной задержкой (1–60 секунд).
- **Уровни QoS:** для каждой метрики можно задать QoS 0, 1 или 2 (по умолчанию 0).
- **Аутентификация:** опциональная поддержка username/password для локального и удалённых брокеров.
- **Плавная остановка:** SIGINT / SIGTERM вызывает корректную остановку — все потоки завершаются, подключения закрываются, ресурсы освобождаются.
- **Валидация конфигурации:** дубликаты секций, дубликаты топиков, отсутствие обязательных полей, недопустимые порты, переполнение буферов — всё проверяется при запуске.
- **Режим отладки:** подробный вывод каждого опубликованного значения, событий подключения и ошибок чтения источников.

## Требования

- **GCC** или любой компилятор C с поддержкой C11
- **pthread** — POSIX-потоки (часть glibc в Linux)
- **libmosquitto** — клиентская библиотека Mosquitto

Установка на Debian / Ubuntu:

```bash
sudo apt install build-essential libmosquitto-dev
```

Установка на RHEL / Fedora:

```bash
sudo dnf install gcc mosquitto-devel
```

## Установка

```bash
sudo make install
```

С параметрами:

```bash
sudo make install HOST=192.168.1.10 PORT=1883 MQTT_USER=sensor MQTT_PASS=secret
```

### Обработка конфигурации при установке

Цель `install` следует этому приоритету для конфигурационного файла:

| Приоритет | Условие | Поведение |
|-----------|---------|----------|
| 1 | `mqtt_pub.ini` существует в папке проекта | Копируется в назначение. Параметры `HOST`, `PORT`, `MQTT_USER`, `MQTT_PASS` применяются поверх через `sed`. |
| 2 | Нет локального конфига, нет конфига в назначении | Создаётся динамически со значениями по умолчанию и переданными параметрами. |
| 3 | Нет локального конфига, конфиг есть в назначении | Обновляются только параметры (`HOST`, `PORT`, `MQTT_USER`, `MQTT_PASS`). Существующие метрики сохраняются. |

### Параметры установки

| Параметр | По умолчанию | Описание |
|-----------|---------|-------------|
| `HOST` | `127.0.0.1` | Адрес брокера (применяется в конфиг) |
| `PORT` | `1883` | Порт брокера (применяется в конфиг) |
| `MQTT_USER` | *(пусто)* | Имя пользователя для аутентификации (применяется в конфиг) |
| `MQTT_PASS` | *(пусто)* | Пароль для аутентификации (применяется в конфиг) |
| `CONF` | `/etc` | Директория назначения для конфигурационного файла |

### Что делает install

1. Останавливает сервис `mqtt_pub`, если он запущен.
2. Устанавливает бинарный файл в `/usr/local/bin/mqtt_pub`.
3. Устанавливает systemd-юнит в `/etc/systemd/system/mqtt_pub.service`.
4. Обрабатывает конфигурационный файл (см. таблицу приоритетов выше).
5. Создаёт/обновляет env-файл в `/etc/default/mqtt_pub` с `PARAMS=-f <путь_к_конфигу>`.
6. Сохраняет `install.log` с путём `CONF` для будущих обновлений.
7. Перезагружает systemd, включает и запускает сервис.

## Удаление

```bash
sudo make uninstall
```

Удаляет бинарный файл, systemd-юнит, env-файл и конфигурационный файл. `install.log` сохраняется.

## Использование

```
Использование: mqtt_pub [-f <config_file>] [-h]
```

| Параметр | Описание |
|-----------|-------------|
| `-f <config_file>` | Полный путь к INI-конфигурационному файлу. По умолчанию — `mqtt_pub.ini` в текущей директории. |
| `-h` | Вывод справки и завершение работы. |

### Пример запуска

```bash
./mqtt_pub -f /etc/mqtt_pub.ini
```

## Конфигурационный файл

См. `mqtt_pub.ini.example` для полного примера и `docs/MQTT_Publisher_RU.md` для подробной документации.

### Краткая справка

```ini
[MQTT]
host=localhost
port=1883
user=sensor
password=secret
debug=0

[cpu_temp]
topic=sensors/rpi/cpu_temp
interval=5
source=/sys/class/thermal/thermal_zone0/temp
key=-
qos=0

[remote_temp]
topic=sensors/weather/temp
source=$10.0.0.5:1883/sensors/weather/temp
key=-
qos=0
```
